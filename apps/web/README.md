# ZERO Web Client

Phase 35 establishes the Next.js web-client foundation and privacy-first onboarding surface.

Authentication, E2EE, device identity, messaging, files, calls and other security-critical runtime integrations remain explicit follow-up work; the UI does not fake provider behavior.
