# ZERO Community Code of Conduct

ZERO is a free, open-source project. We want participation to be constructive, welcoming, and safe.

## Expected behavior

- Be respectful and considerate of contributors with different backgrounds and experience.
- Discuss ideas and code on their technical merits; offer actionable feedback.
- Respect privacy. Never publish another person's private messages, contact information, credentials, or identifying data without permission.
- Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md).

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, stalking, doxxing, sexual harassment, and deliberate disruption are not permitted. Do not use project spaces to distribute malware, phishing, spam, or exploit instructions targeting others.

## Reporting and enforcement

Report conduct concerns privately to repository maintainers through GitHub's available private contact mechanisms. If no private contact channel is available, avoid posting personal or sensitive information publicly. Maintainers may edit or remove harmful content, restrict participation, or ban contributors, with decisions made according to severity and context.

This policy applies to repository issues, pull requests, discussions, and other official ZERO community spaces.
