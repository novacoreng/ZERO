# ZERO Brand Lock

**Status:** LOCKED  
**Date:** 2026-09-23

## Approved identity

ZERO uses an abstract technical disappearing-message symbol in the Glass Lagoon visual direction.

### Canonical assets

- `brand/logo/zero-mark.svg` — primary symbol / app icon source
- `brand/logo/zero-lockup.svg` — full brand lockup
- `brand/README.md` — usage and decision record

### Meaning

The central orb represents a private message or protected communication object. The separated surrounding arcs represent disappearance, expiration, and the removal of persistent traces.

### Usage

- Use the mark alone for the app icon, favicon, compact navigation, notifications, and device surfaces.
- Use the lockup for marketing, onboarding, documentation, and public brand surfaces.
- Preserve the four separated arc structure.
- Do not introduce a padlock, shield, chat bubble, or other generic security symbol into the canonical mark.
- Maintain sufficient clear space around the mark.
- The Glass Lagoon palette is the canonical color direction; monochrome derivatives may be produced only as implementation variants.

## Brand decision

This identity is now part of the ZERO product contract. Future UI work should use these assets rather than inventing a competing logo.
