# ZERO Reporting — Phase 24

Reporting provides a controlled path for users to flag spam, harassment, fraud, abuse, malicious files and security issues without converting ZERO into a plaintext surveillance system.

## Evidence
The reporter chooses what evidence to submit. Evidence is encrypted and stored separately from report metadata. A report does not automatically grant moderators access to all messages in a conversation.

## Moderator access
Moderation uses least privilege. Access to submitted evidence is explicit and auditable. Moderators do not receive a universal account decryption capability.

## Reporter privacy
Reporter identity is private by default. Emergency/security reporting can use a stronger operational workflow.

## Lifecycle
Reports move through bounded states: submitted, triaged, under review, actioned/dismissed, appealed and closed.

## Appeals and false reports
Actions can be appealed. Repeated abusive reporting can itself produce abuse signals, while a single report is not treated as proof of wrongdoing.

## Retention
Report and evidence retention must follow a documented privacy schedule. The current contract target is 90 days, subject to legal/privacy review.

## Limitations
Production moderation tooling, secure evidence-decryption workflow, legal/privacy retention review and independent security review remain required.
