# ZERO Brand

## Locked logo

The ZERO logo direction is locked as of 2026-09-23.

- Direction: Abstract
- Character: Technical
- Color direction: Glass Lagoon
- Core meaning: private communication that can disappear
- Primary mark: central orb surrounded by four separated, rounded dissolving arcs
- Wordmark: ZERO
- Tagline: PRIVATE MESSAGING / THAT DISAPPEARS

The symbol is the primary application icon/brand mark. The wordmark and tagline are supporting lockups.

The canonical vector source is `brand/logo/zero-mark.svg` and `brand/logo/zero-lockup.svg`.

Do not redesign, recolor, or replace the mark without an explicit brand decision.
